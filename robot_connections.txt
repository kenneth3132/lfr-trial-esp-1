## 2. Connection Purposes & Logic

### Sensor Array (RLS-08)
* **Analog (ADC) Interface**: These 8 pins carry variable voltages representing how much light is reflected. They allow the ESP32 to calculate a precise "weighted position" of the line rather than just "line/no-line" data, which is essential for high-speed PID control.

### Motor Driver (TB6612FNG)
* **PWM Pins (PWMA/PWMB)**: These pins deliver a rapid high-frequency signal that allows the ESP32 to control motor speed from 0% to 100% via the PID algorithm.
* **Direction Pins (AIN/BIN)**: By setting one HIGH and the other LOW, you determine the spin direction of each motor.
* **Standby (STBY)**: This is the "Safety Switch". When held LOW, the motors are completely disabled. Keeping it HIGH at GPIO 19 ensures the driver is always ready to receive commands.

### User Interface (Buttons & LED)
* **Internal Pull-Ups (Buttons)**: Your code uses `INPUT_PULLUP`. This means the pin is normally internally pulled HIGH (3.3V). When you press the button, it connects the pin to GND, triggering a "LOW" signal which the ESP32 detects as a button press. This removes the need for external resistors.
* **Onboard LED (GPIO 2)**: This provides visual feedback to the user without needing an OLED. It blinks rapidly during calibration (so you know to move the robot) and turns solid when the robot is actively running in PID mode.
