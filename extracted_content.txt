About This Project

          This is a high-performance 
ESP32-based line follower robot
 that utilizes a PID (Proportional-Integral-Derivative) control algorithm for exceptional tracking accuracy at speed. Unlike basic line followers that simply react to sensor inputs, this robot predicts and compensates for deviations before they become significant errors, resulting in incredibly smooth and stable line tracking even around sharp curves and complex track layouts.

          At the heart of this system is an ESP32 microcontroller paired with a 13-channel TCRT5000L sensor array that provides high-resolution position data. The PID controller constantly calculates the robot's position relative to the line and adjusts motor speeds hundreds of times per second to maintain perfect alignment. The result is a robot that can navigate challenging courses at speeds that would cause conventional line followers to lose their way.

          This project is ideal for robotics competitions, STEM education, and anyone interested in learning advanced control systems. The code includes an interactive OLED menu system that allows you to tune PID parameters, adjust speed settings, and configure sensor thresholds in real-time without needing to re-upload code — making it perfect for track-side tuning and experimentation.

How It Works

Sensor Array Reading

13 IR sensors continuously scan the track surface at high frequency, detecting line position

Position Calculation

Weighted centroid method computes exact line position (0–1300 range) relative to robot center

PID Error Correction

Controller calculates correction = Kp×error + Ki×integral + Kd×derivative

Motor PWM Output

ESP32 generates differential PWM signals via TB6612FNG driver for precise steering

Key Features

          The PID control loop is the star of this project, providing proportional gain for immediate response to line deviations, integral gain to eliminate steady-state error over long curves, and derivative gain to anticipate future errors based on current rate of change. This three-term controller ensures the robot stays locked onto the line with minimal oscillation, even at speeds exceeding 2 meters per second.

          The 
13-channel sensor array
 offers exceptional resolution, allowing the robot to detect even the slightest line drift. Each TCRT5000L sensor uses infrared reflectance to distinguish between the black line and white surface, and the multiplexed reading system ensures all sensors are sampled efficiently without consuming excessive GPIO pins.

          The built-in 
OLED interface
 and 5-button navigation system provide real-time access to critical parameters. You can adjust Kp, Kd, base speed, and sensor thresholds on the fly, with all settings automatically saved to EEPROM. This feature is invaluable for competition scenarios where track conditions vary and rapid tuning is essential.

Circuit Diagram

The circuit diagram below illustrates the complete wiring for the ESP32 PID line follower robot. The ESP32 connects to the 74HC4067 multiplexer for reading all 13 TCRT5000L sensors using just one analog pin. The TB6612FNG motor driver receives PWM signals from the ESP32 for speed control and direction pins for steering. The OLED display and 5‑button keypad provide the user interface for on‑the‑fly parameter tuning.
